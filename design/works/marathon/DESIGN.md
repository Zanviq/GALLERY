# 곧은내 하프마라톤 2027 — DESIGN.md

가상의 도시 곧은내시가 여는 봄 하프마라톤의 홍보 페이지(`works/marathon/`). 토큰은
`works/marathon/css/site.css` 맨 위 `:root`에 같은 이름으로 들어 있고, 페이지 코드는 이름만 쓴다.

> UXKIN이 연결돼 있지 않아 실제 사이트 비교 없이 정했다. 기준은 BRIEF §00·§0, 주인이 좋아한
> 너울 2027(`works/festival/`)의 포스터 감각, 그리고 도로 경주 포스터와 대회 요강(booklet)의
> 관행: 거리 숫자를 크게, 날짜·출발 시각·장소를 한눈에, 나머지는 표와 목록으로 또박또박.

## 1. 방향

**출발선에 붙은 포스터, 넘기면 대회 요강.** 첫 화면은 파란 면 하나에 흰 글자뿐인 포스터다.
대회 이름, 날짜, 출발 시각, 장소, 참가 신청 버튼, 그리고 화면 폭을 꽉 채운 21.0975.
그 아래는 달리는 사람이 알아야 할 것을 요강처럼 조판한다: 코스 지도와 고도, 종목과 참가비,
일정, 메달과 셔츠, 페이스메이커와 관문, 규정과 질문, 신청, 주최. 화면마다 한두 가지만.

- 대회: 제4회 곧은내 하프마라톤. 2027년 4월 4일 일요일, 하프 07:30 출발.
- 장소: 곧은내시 시민광장 출발·도착. 남둑길로 강을 거슬러 올라가 새벽다리에서 건너고 북둑길로
  내려온다. 고저차 14m, 누적 오르막 46m. 모두 가상(곧은내, 남둑길, 북둑길, 둑머리다리,
  갈대숲다리, 물레다리, 새벽다리, 시청다리, 시민광장).
- 상호 충돌 확인: "곧은내", "곧은내시", "곧은내 하프", "곧은내천" 웹 검색 결과 없음 (2026-11-10).
- 결: 포스터는 평평하고 크다. 요강 부분은 표와 숫자 중심, 장식 없음.

## 3. 활자

| 역할 | 서체 | 쓰는 굵기 | 이유 |
|---|---|---|---|
| 디스플레이: 대회 이름, 21.0975, 섹션 제목, 표의 큰 숫자, 시각 | **Gasoek One 가속** (OFL, JAMO) | 400 (한 굵기) | 이름부터 "가속". 쐐기처럼 앞으로 기운 획과 아주 무거운 숫자가 거리와 기록을 그림처럼 만든다 |
| 본문·표·UI | **Spoqa Han Sans Neo** (OFL 1.1, Spoqa). 서브셋 이름 **Goteunnae Sans** | 400 / 700 (CSS의 800도 700 파일로) | 넓고 열린 자면, 낱자 사이가 넉넉한 고딕. 좁고 무거운 Gasoek 아래에서 본문이 숨을 쉬고, 표의 숫자가 또렷하다 |

라틴 서체는 따로 두지 않는다. 두 서체 모두 숫자와 라틴이 충분하다.

- 라이선스: Gasoek One은 OFL 1.1이고 저작권 줄에 Reserved Font Name이 없어 서브셋 이름을 바꾸지 않았다.
  Spoqa Han Sans Neo는 OFL 1.1이고 "with Reserved Font Name Spoqa Han Sans Neo"가 붙어 있어, 서브셋의
  이름 표(1, 3, 4, 6, 16, 그리고 이름을 되풀이하던 7)와 CSS를 모두 **Goteunnae Sans**로 바꿨다
  (`scripts/fonts.py` → `rename_font.py`, `works/marathon/fonts/OFL-goteunnae-sans.txt`).
- 처음 배정은 KoddiUD 온고딕이었으나 OFL이 아니라(한국장애인개발원, 데이터 수정 제한) 바꿨다.
  후보 Freesentation은 라틴이 Roboto에서 왔고 자면이 좁아 Gasoek과 같이 빽빽해져 고르지 않았다.
  Wanted Sans는 keyboard가 쓰고 있다.
- 21.0975: Gasoek One 비례 숫자, 커닝 포함 전진 폭 4.417em, 잉크는 양쪽에서 0.041em 안쪽.
  `font-size: min(100cqi / 4.34, 34svh)`와 `margin-left: -.041em`으로 잉크가 칸 폭에 꼭 맞는다.

## 4. 격자와 간격

- 12칸(1024px 이상), 6칸(600–1023px), 4칸(600px 미만). 최대 폭 1680px.
- 바깥 여백 `--margin`: clamp(20px, 4vw, 64px). 칸 사이 `--gap`: clamp(16px, 2vw, 32px).
- 간격 8px 단위: `--s-1` 8 · `--s-2` 16 · `--s-3` 24 · `--s-4` 32 · `--s-5` 48 · `--s-6` 64 · `--s-7` 96 · `--s-8` 128 · `--s-9` 192
- 섹션 위아래 `--section`: clamp(96px, 12vw, 192px). 한 화면에 제목 하나와 내용 한 덩어리.
- 제목은 1–4칸, 내용은 5–12칸의 비대칭이 기본. 지도와 사진은 1–12칸 또는 화면 끝까지.
- 면 순서: 파랑(포스터) → 사진(끝까지) → 흰(코스) → 검정(종목) → 흰(일정) → 사진 → 흰(기념품)
  → 흰(페이스메이커·관문) → 흰(규정·질문) → 파랑(신청) → 흰(주최) → 빨간 결승선 띠 → 파랑(푸터).

## 6. 컴포넌트

- **버튼**: 파란 면 위 주 버튼은 흰 면 + 검정 글자, hover 시 검정 면 + 흰 글자. 흰 바탕 주 버튼은
  파란 면 + 흰 글자, hover 시 검정 면. 높이 56px, 글자 Goteunnae Sans 700 18px. 화살표 문자 없음.
  focus: 3px 실선 outline, offset 3px (밝은 바탕 검정, 파란·검정 바탕 흰색).
- **종목 줄**: 카드가 아니라 요강의 표 한 줄. 왼쪽에 큰 거리 숫자, 오른쪽에 출발·참가비·정원·제한
  시간·나이를 정의 목록으로. 줄 사이 2px 흰 괘선.
- **경기 시간 막대**: 06:00–11:00 축 위에 종목별 출발부터 결승선이 닫힐 때까지의 막대.
- **관문 표**: 제한 시각만 빨강.
- **묻고 답하기**: `details/summary`, 오른쪽 + 가 열리면 − 로.
- **신청 확인**: 종목과 셔츠 크기 라디오, 확인 버튼. 결과는 같은 자리에 문장으로. 아무것도 보내지
  않는다고 버튼 위에 적는다. 이름·연락처·결제 칸 없음.

## 7. 사진과 지도

- 사진: Gemini 생성, 밝고 또렷한 요즘 스포츠 사진(아침 햇빛, 빠른 셔터). 필름 입자, 어두운 빛,
  흐린 잔상 없음. 사람은 찍지 않는다(2026-11-10 주인 리뷰): 빈 출발선, 채워 둔 컵, 배번, 페이스메이커 깃발, 걸어 둔 메달처럼 대회의 물건과 자리로 말한다. 글자와 실제 상표 없음(배번 숫자 하나만 예외).
  물건 색은 흰·검정·파랑·빨강으로 맞춰 페이지와 한 벌로 보이게. 메달과 셔츠는 같은 콘크리트 바닥,
  같은 빛에서 찍은 한 벌. 사진은 항상 네모난 틀 안에 놓고 페이지 색 위에 오려 붙이지 않는다.
- 지도: 코드로 그린 선 지도(`scripts/course.py`가 만든 인라인 SVG). 강은 옅은 파랑 면, 길은 가는
  회색 선, 하프 코스는 굵은 파랑 선, 10km·5km 걷기의 반환 다리는 검정 선, km 표시는 흰 원에
  숫자, 급수대는 검정 네모, 출발·도착은 빨간 테이프. 폰에서는 같은 지도를 90도 돌려 코스가 화면
  아래로 흐르게 한다(북쪽이 오른쪽, 지도에 표시).
- 고도 그래프: 0–40m 축의 평범한 면 그래프. 과장하지 않으려고 축을 0에서 시작한다.
- 아이콘 없음.
