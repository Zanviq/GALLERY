# 물길 (Mulgil) — DESIGN.md

가상 회사. 무인 수거선으로 바다 쓰레기를 해변에 닿기 전에 줍는 통영의 스타트업.
사이트: `works/startup/` · 토큰 원본: `works/startup/css/site.css` 맨 위 `:root`.

> 방향 근거: UXKIN 이 연결되어 있지 않아 실제 사이트 비교 없이 정했다. 대신 이 회사의 세계에서
> 가장 고유한 시각 언어인 **종이 해도(nautical chart)** 의 관례를 가져왔다: 흰 깊은 바다, 옅은 파랑 얕은 바다,
> 담황색 육지, 잉크색 해안선, 자홍색(magenta) 주기, 수심 숫자, 테두리 눈금.
> 해양 스타트업의 흔한 기본값(짙은 파랑 그라디언트, 물결 SVG, 빛나는 입자)을 피하기 위한 선택.

## 원칙

1. **해도가 브랜드다.** 정체성은 지도(시그니처 캔버스)와 선체 도면에 몰아 쓴다. 나머지는 조용하게.
2. **형용사 대신 메커니즘.** 주장에는 단위가 붙은 숫자와 측정 방법, 혹은 그림이 붙는다.
3. **색은 의미다.** 주황 = 보트(제품), 자홍 = 예보. 장식으로 쓰지 않는다.
4. **잉크와 바다색.** 평면 색. 그라디언트·글로우·유리 효과 없음. 그림자는 떠 있는 컨트롤 하나에만.
5. **짧고 평범한 한국어.** 한 문장에 한 생각.

## 글꼴

- **Hahmlet** (가변, 500–650): 제목, 해도의 바다 이름. 해도는 물의 이름을 세리프로 쓴다.
- **IBM Plex Sans KR** (400·500·600): 본문, UI, 데이터. 숫자는 `tabular-nums`. 고정폭 글꼴은 쓰지 않는다.
  CSS 별칭은 `'Mulgil Sans'` — 잘라 낸(수정한) 글꼴에 예약 글꼴 이름 "Plex"를 쓰지 않기 위해서다 (OFL RFN).
- 두 글꼴 모두 페이지에 실제로 쓰인 글자만 잘라 `fonts/` 에 자체 호스팅 (woff2, `font-display: swap`).
  Hahmlet 은 제목·워드마크·해도 바다 이름 글자만 (`scripts/fonts.py`, 문구를 바꾸면 다시 실행).

## 간격·레이아웃

- 4px 기반: 4, 8, 12, 16, 24, 32, 48, 64, 96, 144.
- 섹션 위아래 `--section`: clamp(96px, 11vw, 168px).
- 내용 최대 폭 1240px, 좌우 여백 clamp(20px, 5vw, 64px). 12단 그리드, 간격 24px(모바일 16px).
- 글은 왼쪽 정렬. 제목은 5–6단, 내용은 오른쪽 6–7단으로 어긋나게 배치해 매 섹션이 가운데 정렬로 보이지 않게.

## 모양·깊이

- 반경: `--r-1` 4px (패널, 표 칩), `--r-2` 8px (버튼·입력칸). 원형은 아이콘 버튼만.
- 그림자: `--lift` 하나 — `0 1px 0 rgb(19 41 61 / .06), 0 12px 32px -16px rgb(19 41 61 / .28)`. 해도 위에 뜨는 패널에만.
- 선: 1px `--rule`. 해도·도면 안에서는 0.75–1.25px 잉크선.

## 컴포넌트

- **버튼**: 기본 = 잉크 바탕 흰 글자 48px 높이. 보조 = 투명 바탕 잉크 1px 테두리. 조용한 = 밑줄 링크.
  hover 는 바탕을 한 단계 밝게(`#1E3A52`), 눌림은 1px 아래로, 비활성은 40% 투명·커서 기본.
- **포커스**: 모든 조작 요소에 `outline: 2px solid var(--magenta); outline-offset: 3px`. 어두운 띠에서는 `#F08BC4`.
- **링크**: 잉크 글자 + 1px 밑줄(`--rule`), hover 시 밑줄 `--magenta`.
- **입력칸**: 흰 바탕, 1px `--rule`, 48px, 라벨은 위에. 오류는 테두리 `--error` + 아래 문장 + 아이콘. 도움말은 `--ink-3`.
- **패널(해도 위)**: 흰 바탕, 1px `--rule`, `--lift`, 반경 4px. 해도의 범례 상자를 닮게.
- **표**: 머리 행 `--shoal-2`, 숫자는 오른쪽 정렬 tabular.
- **아코디언(채용)**: 행 전체가 버튼, 펼침 표시는 + / − 선 아이콘, `aria-expanded`.
- **헤더**: 흰 바탕 64px 고정, 아래 1px 선. 모바일은 메뉴 버튼 → 전체 폭 시트.
- **푸터**: `--night` 바탕, 한 줄 고지 "가상 회사입니다. zanviq gallery 작품."

## 이미지·아이콘

- 사진 없음. 모든 그림은 코드: 해도(캔버스), 선체 도면(SVG), 팀 초상(음향측심 선 초상, Pillow → webp).
- 아이콘: 1.5px 선 SVG, 24px 격자, 끝 둥글게. 직접 그린 소수만 (화살표, 플러스, 체크, 경고, 바람).
- 이모지·스톡·실제 로고 없음.

## 움직임

- 움직임은 해도 하나에. 페이지 다른 곳은 사용자가 누른 것에만 반응 (펼침, 성공 상태).
- 시간: 짧은 반응 160ms, 패널·상태 전환 320ms, 카메라 이동 1100ms. 가속 `cubic-bezier(.2,.7,.2,1)`.
- `prefers-reduced-motion`: 해도는 단계마다 미리 계산한 정지 장면으로 바뀐다. 카메라 이동 없음, 입자 정지.

## 운영 메모

- 시그니처 해도: `js/chart/` (world = 지형·정적 레이어, sim = 조류·수렴선·입자·보트, render = 프레임, story = 단계·카메라·조작).
  지형은 시드 고정 노이즈로 매번 같게 만들어진다. 섬·양식장·수렴선 좌표는 `world.js` / `sim.js` 맨 위.
- 쿼리: `?capture` 성숙한 첫 장면(썸네일·OG 촬영용), `?still` 해도 전체 정지 화면(`img/chart-still.webp` 촬영용, 1600×1000),
  `?fallback` 캔버스 대체 화면 확인용, `?debug` 콘솔에서 `__chart` 접근.
- 촬영: 헤드리스 Chrome 에서 `/shared/back.js` 요청을 막고 `?capture` 를 1200×900(썸네일)·1200×630(OG)로 찍었다.
- 팀 초상: `scripts/portraits.py` (Sounding Lines, PHILOSOPHY.md). 파비콘: `scripts/icons.py`.
