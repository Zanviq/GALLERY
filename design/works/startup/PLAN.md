# 물길 — 디자인 계획 (frontend-design 패스)

## 주제
- 회사: 물길 (Mulgil). 윤슬포 기지(가상 지명). 무인 수거선 "누비"를 쓰레기가 모이는 바다 위 수렴선으로 보낸다.
- 독자: 지자체·항만·양식 단지 담당자, 투자자, 지원자.
- 페이지의 일: "쓰레기는 바다 위에서 한 줄로 모이고, 그 자리는 계산할 수 있다"는 것을 보여 주고 도입 문의로 이끈다.

## 토큰 (요약 — 전체는 DESIGN.md)
- 색: sea `#F4F7F7` · ink `#13293D` · shoal `#D3E6EE` · land `#E9DCAF` · magenta `#A8186F` (예보) · signal `#E2531C` (보트)
- 글꼴: Hahmlet (제목, 바다 이름) + IBM Plex Sans KR (본문·UI·숫자). 고정폭 없음.
- 레이아웃: 12단, 왼쪽 정렬, 제목과 내용이 어긋난 두 단.

## 레이아웃 스케치

히어로 (데스크톱): 왼쪽 종이 단에 제목, 오른쪽에 테두리 눈금이 있는 해도. 스크롤하면 종이 단이 걷히며 해도가 화면 전체가 된다.
```
+---------------------------------------------------------------+
| 물길          작동 방식 누비 현장 기록 팀 채용      [도입 문의] |
+----------------------+----------------------------------------+
| 바다 쓰레기를        |▚▞ 34°52′ ▚▞▚▞▚▞▚▞▚▞▚▞▚▞▚▞▚▞▚▞▚▞▚▞▚▞ |
| 해변에 닿기 전에     |  ░░육지░░   · 12  ·9      [해역 HUD]  |
| 줍습니다.            |     ╲  - - 수렴선 - -  ▲누비 03       |
|                      |   (섬)   ·  · · ·  ·     (섬)        |
| 설명 2줄             |          ▲누비 01 ~~~~                |
| [도입 문의하기]      |                                        |
| 어떻게 하는지 보기   | 지형은 설명을 위해 단순화했습니다.     |
+----------------------+----------------------------------------+
```
이야기 단계 (데스크톱): 해도 고정, 왼쪽에 범례 상자 같은 패널이 스크롤로 지나간다. 오른쪽 아래 4단계 레일.
```
+---------------------------------------------------------------+
| [패널: 해변에 닿으면 이미 늦습니다]      해도 (카메라 이동)      |
|                                          [1 예보 2 출항 3 수거 4 하역] |
+---------------------------------------------------------------+
```
모바일: 해도가 위 58%, 글은 아래 종이 시트. 이야기 단계에서는 해도가 화면 전체, 카드가 아래에서 올라온다.

이후 섹션 (정적, 조용하게):
```
누비      [제목 5단]             [측면도·평면도 SVG 7단 + 번호 지시선]
          [제원 표 — 도면 번호와 연결]
현장 기록 [제목]  [해역별 표]  [구성비 막대 1줄]  [잘 안 된 점]
팀        [창업자 2명 큰 초상 + 긴 소개] [4명 작은 목록]
함께하는 곳 [투자 라운드 표] [협력 문장 목록]
채용      [아코디언 4행, 행 안에서 지원 폼 → 성공 상태]
문의 (어두운 띠) [제목·연락처 5단] [폼 7단 → 성공 상태]
푸터      한 줄 고지 + 링크
```

## 원칙
1. 해도가 브랜드다. 2. 메커니즘을 보여 준다. 3. 주황 = 보트, 자홍 = 예보. 4. 평면 색. 5. 짧은 한국어.

## 브리프 대조 리뷰 (수정한 것)
- 처음엔 HUD·좌표에 IBM Plex Mono 를 쓰려 했다 → "작은 데이터 라벨에 고정폭" 은 생성 페이지의 흔한 신호. Plex Sans KR 의 tabular 숫자로 바꿨다.
- 처음엔 히어로를 해도 전체 화면 + 가운데 제목으로 생각했다 → 가운데 정렬 히어로는 금지 목록. 왼쪽 종이 단 + 오른쪽 해도로 바꾸고, 그 종이 단이 걷히는 순간을 유일한 연출로 삼았다.
- 섹션마다 작은 영문 대문자 라벨을 붙이려 했다 → 삭제. 번호는 실제 순서인 4단계와 도면 지시선에만.
- 팀을 3단 동일 카드로 두려 했다 → 창업자 2명/나머지 4명으로 위계를 나눴다.
- 숫자 강조 블록(큰 숫자 + 작은 라벨) 대신 해역별 표와 측정 방법 주석.
- 보조 색이 둘(주황·자홍)이라 규칙을 엄격히: 둘 다 글자색으로 쓰지 않고, 주황은 보트, 자홍은 예보·포커스·링크 밑줄.
