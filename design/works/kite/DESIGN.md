# 훨훨 2027 — DESIGN.md

가상의 겨울 연날리기 축제 **훨훨 2027**(제5회 하늬강 정월 연날리기) 홍보 페이지(`works/kite/`)의 디자인 결정.
토큰은 `works/kite/css/site.css` 맨 위 `:root` 에 같은 이름으로 들어 있다.

> UXKIN 이 연결돼 있지 않아 실제 사이트 비교 없이, 브리프와 갤러리의 01 가락 65 · 02 너울 2027 · 03 담금을
> 직접 열어 보고 정했다. 셋의 공통점(색 한 면, 화면만 한 활자, 포스터 격자, 사물 사진, 정보 먼저, 감각 하나)을 따른다.

## 1. 한 줄 방향

**하늘 한 장이 포스터.** 페이지의 바탕이 정월 대낮의 하늘이고, 사진으로 찍은 연이 코드로 그린 줄과 꼬리를 달고 그
하늘에 떠 있다. 화면 아래쪽 띠는 사진 속 빈 둔치(하늘을 잘라 내 페이지 하늘과 이어짐). 활자는 연날리기 안내문처럼
크고 둥글고 분명하게: 언제, 어디서, 누구나, 무엇을 하는지가 첫 화면에 다 있다.

- 이름: 훨훨 2027 · 제5회 하늬강 정월 연날리기 (가상)
- 날짜: 2027년 2월 20일(토)–21일(일, 정월대보름). 대보름은 한국천문연구원 역법 자료 기준 2월 21일
- 장소: 하늬시 하늬강 바람둔치 (가상). 주최 하늬시, 주관 하늬연보존회 (가상)
- 이름의 뜻: 액막이연의 줄을 끊어 보내며 "훨훨 날아가라". 마지막 순서와 이름이 같다.

## 2. 색

| 토큰 | 값 | 역할과 이유 |
|---|---|---|
| `--sky` | `#59B7F0` | 페이지의 하늘 면. 히어로, 연 목록, 챙길 것. 겨울 대낮의 맑은 하늘(연 사진을 같은 하늘색 배경지에서 찍어 테두리가 섞인다) |
| `--ink` | `#0B0C0D` | 글자, 연줄, 겨루기 규칙 면. 방패연 반달·꼬리연 테두리의 먹 |
| `--paper` | `#FFFFFF` | 한지. 프로그램·오시는 길 면, 먹 면 위 글자 |
| `--red` | `#D7142C` | 연 꼭지의 빨강. 가오리연, 붉은 꼭지, 액막이연 면, 강조 숫자. 주황·주홍 쪽이 아닌 순수한 빨강 |
| `--sky-2` | `#8FCFF6` | 하늘 면 안의 옅은 칸(입력이 아니라 표의 머리) |
| `--ink-2` | `#3B4148` | 흰 면의 보조 글자 |

대비(`scripts/contrast.py`): ink/sky 8.8, ink/sky-2 11.6, ink/paper 19.6, ink-2/paper 10.3, red/paper 5.2,
paper/red 5.2, paper/ink 19.6, red/ink 3.75 (큰 숫자에만), sky/ink 8.8 (바닥 워드마크). 쓰지 않는 조합:
paper/sky 2.2 (글자 금지), red/sky 2.3 (면·도형만), ink/red 4.0 (큰 글자만).

금지 팔레트 밖: 크림·베이지 없음(한지는 순백), 주황·주홍 없음(빨강은 파랑 쪽으로 기울지도 않는 중성 빨강),
그라데이션·블러·글로우 없음. 하늘은 평평한 면이고 깊이는 연의 크기(가까운 연이 크다)로만 낸다.

## 3. 활자

| 역할 | 서체 | 쓰임 |
|---|---|---|
| 디스플레이 | **카페24 단정해** (SIL OFL 1.1, © Cafe24 Corp., RFN 없음) — 부분집합 이름 **Hanui Display** (2026-11-14, Jua 에서 바꿈) | 훨훨, 날짜, 섹션 제목, 큰 숫자, 연 이름 |
| 본문·UI | **Freesentation 프리젠테이션** 400 / 700 (OFL 1.1, RFN 없음) — 부분집합 이름 **Hanui Text** | 본문, 표, 단추, 바람 읽기 |

- Freesentation 의 OFL 은 Reserved Font Name 을 두지 않지만 이름 표에 "Freesentation is a trademark of Lee Juim"
  이 있어, 부분집합(수정본)의 글꼴 이름을 `Hanui Text` 로 바꿨다. 라틴은 Roboto 기반이라 숫자·영문이 단단하다.
  그래서 Rubik 은 쓰지 않았다.
- 단정해는 굵고 조금 좁은 고딕에 붓으로 끊어 낸 듯한 획 끝이 남아 있어, 한지·대나무로 만든 연과 정월 행사의
  손맛이 난다. 화면만 한 크기에서도 무너지지 않는 포스터 활자. 이름 표에 "Cafe24 Danjunghae is a trademark of
  cafe24" 가 있어 부분집합(수정본) 이름을 `Hanui Display` 로 바꿨다(`fonts/OFL-HanuiDisplay.txt`). en dash 는
  이 글꼴에 없어 Hanui Text 로 떨어진다. (Jua 는 BRIEF §0000 의 'AI 기본 글꼴'이라 바꿨다.)
- 크기: 훨훨 clamp(150px, 27vw, 430px) (휴대폰 46vw), 날짜 clamp(52px, 6.6vw, 112px), 섹션 제목
  clamp(52px, 7.4vw, 128px), 큰 숫자 clamp(72px, 10vw, 168px), 리드 clamp(19px, 1.5vw, 23px)/1.6,
  본문 17px/1.75, 작은 글자 14px/1.55.
- 대문자 머리표·섹션 번호 없음. 번호는 실제 순서가 있는 곳(액막이연 네 단계, 겨루기 규칙)에만.
  메타 정보는 가운뎃점으로 잇지 않고 줄을 나눠 쌓는다. `word-break: keep-all`.

## 4. 격자와 간격

- 12칸, 최대 폭 1600px, 바깥 여백 `--gutter` clamp(16px, 3vw, 40px), 칸 사이 같은 값.
- 섹션 위아래 `--section` clamp(88px, 11vw, 176px). 4px 단위 간격(`--s-1` 4 … `--s-10` 128).
- 섹션 머리: 제목 1–7칸, 리드 8–12칸(넓은 화면), 둘 다 위에 3px ink 괘선. 표 안쪽만 1px.
- 섹션은 면 색으로 나눈다: 히어로(sky) → 이틀(paper) → 연(sky) → 연싸움(ink) → 액막이연(red) →
  오시는 길(paper) → 오기 전에(sky) → 바닥(ink).
- 모서리 0, 그림자 없음. 예외: 연 사진 컷아웃의 아주 옅은 바닥 그림자는 사진에 원래 있던 것만.

## 5. 사진

생성 사진(Gemini), 사람·손·얼굴 없음. 연과 얼레는 하늘색 배경지 앞에서 정면으로 찍게 한 뒤 배경을 알파로 잘라
(`scripts/cutout.py`) 하늘 면 위에 그대로 띄운다. 방구멍도 뚫린다. 둔치 풍경은 하늘을 잘라 내 히어로 아래 띠가 된다.
공방 탁자 사진만 사각 프레임(흰 면 위). 기록은 `IMAGES.md`.

## 6. 섹션

1. **히어로 (sky)**: 왼쪽 위 거대한 '훨훨'과 회차 한 줄, 오른쪽 하늘(7–12칸)에 연 넷(사진) + 줄·꼬리(코드).
   둔치 사진 띠의 지평선 위에 사실 줄 넷: 날짜(Hanui Display, 크게) / 장소·시간·입장 무료·셔틀 / 한 문단과 단추 /
   '이 화면의 바람' 읽기(보퍼트 이름 + 초속)와 '바람 불기'·'바람 소리'. 줄은 사실 줄보다 위에서 화면 밖
   (날리는 사람 쪽)으로 나가 글자를 지나지 않는다. 1023px 아래는 이름, 연 칸, 날짜·사실, 문단, 바람, 땅 순서.
2. **이틀 (paper)**: 토·일 두 칸 진행표. 시각(Hanui Display) / 프로그램(700) / 자리·인원·재료비. 시간표 격자·표 쪽 아님.
   그 아래 공방 탁자 사진과 공방 안내, 연 빌려 주는 곳.
3. **연 (sky)**: 컷아웃 연 다섯(방패연 붉은꼭지, 반달연, 가오리연, 꼬리연, 육모얼레)을 크기가 다르게 놓은 도록.
   이름(Hanui Display) + 크기·살·종이·꼬리·누구에게 표. 같은 바람에 살짝 흔들린다.
4. **연싸움 (ink)**: 큰 숫자 셋(3분, 20m, 64명)과 규칙 여섯 줄. 강조 빨강.
5. **액막이연 (red)**: 줄이 끊긴 흰 방패연 하나가 바람에 떠 있고(같은 엔진), 네 단계와 시각.
6. **오시는 길 (paper)**: 선으로 그린 둔치 지도(강, 둑길, 마당, 주차장, 셔틀 정류장), 주소 + 가상 주소 고지, 셔틀·걷기·차.
7. **오기 전에 (sky)**: 챙길 것 / 두고 올 것 / 날씨에 따라.
8. **바닥 (ink)**: 훨훨 워드마크, 주최·주관, "가상 축제입니다. zanviq gallery 작품."

## 7. 컴포넌트

- 링크 단추: ink 면 + paper 글자, 높이 52px, hover 시 red 면. 하늘 면 위 보조 링크는 밑줄.
- 바람 소리 단추: 2px ink 테두리 48px, `aria-pressed`, 켜지면 ink 면.
- 포커스: 3px 실선 outline, offset 3px. sky·paper 면에서 ink, ink·red 면에서 paper.
- 표: 1px 선(sky 면에서 ink 25%, paper 면에서 ink 18%), 머리 칸 700.
- 메뉴(900px 미만): '메뉴' 단추 `aria-expanded`, 헤더 아래로 펼쳐지는 판, Esc 로 닫기.

## 9. 움직임

움직이는 것은 바람 하나(INTERACTION.md). 섹션이 떠오르는 효과, 부드러운 스크롤 외의 전환 없음.
UI 전환 160ms. `prefers-reduced-motion: reduce` 에서도 잔바람·돌풍·연·꼬리는 움직인다(진폭 0.55배, 속도 0.6배).
꺼지는 것은 부드러운 스크롤뿐(이 페이지엔 패럴랙스·스크롤 연동·큰 슬라이드가 원래 없다).
