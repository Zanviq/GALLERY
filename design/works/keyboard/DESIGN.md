# 가락 GARAK — design system

가상 브랜드 **가락**(GARAK)의 첫 키보드 **가락 65** 출시 페이지. 이름은 손가락의 '가락'과 장단의 '가락'을 겹친 것.
페이지의 일은 하나다: 방문자가 자기 키보드를 눌러 화면 속 키보드를 직접 쳐 보게 하고, 그 다음에 구조·스위치·색·사양을 읽고 예약하게 한다.

> 방향은 실제 사이트 비교(UXKIN 미연결) 없이 주제와 재료에서 정했다. 비교한 사이트 없음.
> 같은 갤러리의 다른 세 작품이 모두 Hahmlet + IBM Plex Sans KR 을 써서, 이 작품은 일부러 다른 글꼴로 갔다.

## 방향

**측정 도면 + 양극산화 알루미늄.** 배경은 무광 알루미늄 같은 차가운 회색. 정보는 기술 도면처럼 가는 지시선, 실제 치수, 힘-거리 곡선으로 보여 준다.
색은 제품에서 온다: 페이지의 강조색은 언제나 지금 고른 색 구성의 포인트 키캡(Esc·Enter) 색이다.
버튼은 키캡처럼 눌린다 (아래 모서리 두께, 누르면 1px 내려감). 그 외에는 조용하게.

하지 않는 것: 보라/파랑 그라데이션, 그라데이션 글자, 글로우, 유리 효과, 같은 카드 3열, 가운데 정렬 히어로 + 버튼 두 개, 모든 제목 위 영문 대문자 라벨, 'A · B · C' 메타 문자열, 섹션마다 fade-in-up, 작은 데이터 라벨용 고정폭 글꼴.

## 간격과 배치

- 4px 단위: 4 8 12 16 24 32 48 64 96 128 160.
- 섹션 위아래: clamp(96px, 12vw, 176px). 본문 최대폭 1320px, 바깥 여백 clamp(16px, 4vw, 48px).
- 12칸 그리드, 기본은 왼쪽 정렬. 큰 제목은 왼쪽에, 설명은 7–9칸 사이 좁은 열에.
- 가운데 정렬은 쓰지 않는다 (예약증 번호만 예외).

## 모양과 깊이

- 반경: `--r-1` 4px (입력칸, 작은 칩), `--r-2` 9px (키캡 버튼), `--r-3` 18px (3D 무대, 카드). 원형은 색 칩만.
- 그림자는 하나: **키캡 두께** `inset 0 -3px 0 rgb(0 0 0 / .22)` + 눌림 시 1px 내려감. 다른 면에는 그림자 없음, 가는 선으로 나눈다.

## 구성 요소

- **버튼(키캡)**: 기본 = accent 채움 + on-accent 글자, 높이 52px, 9px 반경, 아래 3px 두께. hover = 두께 4px로 1px 올라옴. active = 두께 1px, 2px 내려감. disabled = 0.45 투명도, 두께 없음. 보조 = paper-2 채움 + ink 글자 + line-ui 테두리. 조용한 버튼 = 밑줄 텍스트.
- **소리 토글**: 헤더 오른쪽에 늘 보인다. 스피커 아이콘 + '소리 꺼짐/켜짐', `aria-pressed`.
- **선택 칩**(스위치·색 구성·구성): 라디오. 선택 = ink 2px 테두리 + 체크 아이콘, 강조색 점.
- **입력칸**: 52px, paper-2 바탕, line-ui 1px 테두리, 오류 = error 테두리 + 아래 문장.
- **지시선 라벨**: 1px ink 선 + 3px 점, 13px 라벨. 활성 층만 진하게.
- **헤더**: 투명 → 스크롤하면 paper 92% + 아래 가는 선. 모바일은 로고·소리·예약만.
- **푸터**: night 바탕, 페이지 내 링크, '가상 브랜드입니다. zanviq gallery 작품.'

## 이미지와 아이콘

- 사진 없음. 키보드는 Three.js 로 절차적으로 만든 3D. WebGL 이 없으면 같은 장면을 미리 렌더한 `img/fallback.webp`.
- 아이콘은 인라인 SVG, 20px 격자, 1.6px 선, 둥근 끝. 스피커, 체크, 이전/다음, 더하기.
- 로고: 키캡 세 개, 가운데 하나가 눌려 내려간 모양 (장단 한 마디). 워드마크 'GARAK' 은 Archivo wdth 125, 800.

## 작업 기록 (스킬별로 바뀐 것)

- landing-page / web-design-system: 섹션 순서(히어로+분해 → 스위치 → 색 → 타건 → 사양 → 예약 → 묻는 것)와 회색 알루미늄 방향. UXKIN 미연결.
- frontend-design: 다른 갤러리 작품과 겹치던 Hahmlet+Plex 대신 Wanted Sans + Archivo(넓은 폭)로 교체, 고정폭 글꼴 제외, 버튼을 키캡으로.
- interaction-design: 캔버스 하나를 무대 사이로 옮기는 구조, 터치 70ms 판정, 스페이스 예외 규칙, 타건 테스트·예약 상태 기계 (INTERACTION.md).
- canvas-design: 'Measured Strike' 철학(philosophy-measured-strike.md) → 로고(가운데가 눌린 키캡 셋), 공유 이미지의 치수선, 황동 각인.
- ux-copy: 염료승화 표현, 터치 기기·WebGL 없음용 히어로 문장, 예약증 조사(주소로) 등.
- design-elevation: 섹션 간격 축소, 키캡 옆면 UV 번짐 제거, 스위치 하우징 색, 범례 크기, 선택 색.
- accessibility-review: 소리 토글 이름(label in name), 분해 목록을 화면 낭독기에 남김, 라디오 이름·설명 연결, 터치 영역 44px, 10초 뒤 정지.
- web-review: 좁은 화면 색 섹션 순서(무대가 칩 위), 태블릿 지시선, 휴대폰 곡선 글자, hidden 속성 버그, WebGL 없음 정지 이미지 위치.
