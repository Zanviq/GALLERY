# 가락 GARAK — design system (2차, 2026-11-10)

가상 브랜드 **가락**(GARAK)의 첫 키보드 **가락 65** 출시 페이지. 이름은 손가락의 '가락'과 장단의 '가락'을 겹친 것.
페이지의 일은 하나다: 제품을 사진으로 보여 주고, 구조·키캡·스위치·색·사양을 읽힌 뒤 1차 예약으로 보낸다.

## 무엇이 바뀌었나 (1차 → 2차)

- **3D 와 소리를 모두 뺐다.** Three.js 키보드, 분해 애니메이션, 타건 테스트, WebAudio 소리 토글, 힘-거리 곡선
  선택기를 지웠다. `vendor/three`, `js/scene.js` `model.js` `audio.js` `typing.js` `layout.js` `data.js` `main.js`,
  미리 렌더한 `fallback*.webp` 도 삭제. 남은 스크립트는 예약 폼 하나(`js/reserve.js`, 3.7 KB).
- **사진으로 다시 만들었다.** 같은 키보드 한 대를 `--ref` 로 이어 찍은 생성 사진 9컷(IMAGES.md):
  히어로(오른쪽 앞 모서리), 위에서 본 컷, 부품을 펼친 컷(분해 3D 대신), 키캡 매크로, 옆모습, 색 셋, 책상.
- **색을 다시 정했다.** 겨자색(치자) 강조와 회색 알루미늄 바탕을 버렸다. 아래 '색'.
- **포스터처럼.** 너울 2027(`works/festival/`)처럼 평평한 색 한 면, 화면 폭만 한 활자, 3px 괘선, 넓은 여백.
  섹션마다 한 가지만 보여 준다.
- **키캡은 무각.** 생성 사진의 각인은 가짜 글자가 되므로 제품 자체를 '글자 없는 키캡'으로 정하고, 그것을 페이지의
  이야기 하나로 삼았다(각인 세트는 따로 판매). 가스켓 수는 사진에 찍힌 대로 14개로 고쳤다.

## 방향

**배경지와 페이지가 같은 종이.** 스튜디오 컷의 분홍 배경지를 보정해 페이지 바탕과 같은 값으로 맞췄다. 키보드가
페이지 위에 놓인 것처럼 보이고, 사진의 테두리가 없다. 활자는 그 종이 위에 인쇄된 포스터 글자처럼 크게.

하지 않는 것: 가운데 정렬 히어로 + 버튼 둘, 영문 대문자 머리표, 섹션 번호(부품 번호는 실제 쌓는 순서라 예외),
카드 3열, 그라데이션, 유리, 그림자 효과, 섹션마다 떠오르는 애니메이션, 숫자 올라가는 카운터.

## 색

| 토큰 | 값 | 역할과 이유 |
|---|---|---|
| `--field` | `#F6A3C2` | 페이지 바탕. 촬영 배경지이자 연분홍 키캡의 색. 사진 네 장의 종이를 이 값으로 보정 |
| `--case` | `#D12F6B` | 진달래 케이스의 아노다이징 색(히어로 사진 앞면에서 뽑음). '색' 섹션과 바닥글의 면, 곡선의 작동점 |
| `--ink` | `#2E0A1A` | 사진 속 그림자 색을 끝까지 어둡게 한 것. 모든 글자, 괘선, 주 버튼, 예약 섹션의 면 |
| `--ink-2` | `#66183A` | 보조 글자 |
| `--on-case` | `#FFFFFF` | 케이스 면 위 글자 |

이유: 1차 생산분의 색이 **진달래**(1차 300대 한정, 2차부터는 은과 먹만)이고, 페이지는 그 제품을 찍은 종이 위에
있다. 색은 고른 것이 아니라 제품과 촬영에서 왔다: 바탕 = 배경지·키캡, 강조 면 = 케이스, 글자 = 그림자.
금지 팔레트(겨자·주황·크림·보라·세이지 등) 밖이고, 갤러리의 다른 작품과도 겹치지 않는다(분홍을 쓰는 adopt 는
연한 파스텔 + 차콜, riso 는 형광 잉크 강조).

대비: ink/field 9.3, ink-2/field 6.2, 흰 글자/case 4.85, field/ink 9.3, 포커스 링 ink/case 3.7,
입력칸 테두리(field 55%)/ink 3.6. field/case 2.5 는 글자에 쓰지 않는다.

## 글꼴

| 역할 | 글꼴 | 쓰임 |
|---|---|---|
| 한글 전부 | **Wanted Sans Variable** (OFL, RFN 없음) wght 400–1000 | 히어로 '가락' 1000, 제목 900, 본문 450 |
| 라틴 숫자·워드마크 | **Archivo** (OFL, RFN 없음) wdth 125, wght 800 | '65', 6.5°, 사양 숫자, 부품 번호, GARAK |

두 글꼴 모두 페이지 글자만 남겨 woff2 로 잘랐다(`scratch/subset.py`, 68 KB + 31 KB). 확인: `scripts/fontcheck.py`.

## 크기와 격자

- 12칸, 바깥 여백 clamp(16px, 3vw, 40px), 최대 폭 1600px. 섹션 위아래 clamp(104px, 13vw, 200px).
- 히어로 제목 clamp(120px, 17vw, 330px), 휴대폰 26vw. 섹션 제목 clamp(44px, 6.4vw, 112px).
- 섹션 머리는 왼쪽 제목(1–7칸) + 오른쪽 리드(8–12칸), 둘 다 위에 3px 괘선. 표 안쪽만 1px.
- 모서리 0. 그림자 없음.

## 섹션 순서

히어로(포스터 + 모서리 사진) → 소개와 위에서 본 사진, 숫자 넷 → 여덟 겹(부품 사진에 번호) → 글자 없는 키캡 →
옆모습 6.5° → 스위치 셋(정적 힘-거리 곡선) → 색 셋(케이스 면) → 책상 → 사양 → 1차 예약(그림자 면) → 묻는 것 → 바닥(케이스 면).
