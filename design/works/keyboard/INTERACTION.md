# 가락 65 — interaction (2차)

1차의 3D 타건, 분해 스크롤, 소리, 타건 테스트는 모두 뺐다. 이 페이지는 보여 주는 페이지이고, 움직이는 것은 없다.
남은 상호작용은 셋.

1. **페이지 안 이동.** 머리의 링크와 '1차 예약하기' 버튼. `prefers-reduced-motion: no-preference` 일 때만 부드럽게 스크롤.
2. **자주 묻는 것.** `<details>` 그대로. 더하기 아이콘이 45° 돈다(움직임 줄이기에서는 바로 바뀜).
3. **1차 예약 폼** (`js/reserve.js`). 아무 데도 보내지 않는다고 폼 아래와 결과에 적었다.
   - 구성(완성품 398,000 / 베어본 298,000) → 합계가 바로 바뀜. 베어본이면 스위치 칩이 꺼지고 이유 문장이 보인다.
   - 이메일: 빈칸이나 형식 오류면 입력칸 아래 문장 + `aria-invalid`, 포커스를 입력칸으로.
   - 제출 → 예약증(번호, 구성, 색, 스위치, 합계, 메일 문장)이 폼 자리에 나오고 포커스가 예약증으로 간다.
     `localStorage`(`garak65-reservation`, try/catch)에 남겨 다시 열어도 보이고, 저장이 막혀도 동작한다.
   - '다시 고르기' → 저장을 지우고 폼으로, 포커스는 구성 라디오.
   - 라디오는 실제 `input` 을 숨기고 라벨 전체를 누르는 영역(높이 48–64px)으로. 선택은 3px 테두리 + 옅은 면, 포커스는 3px 바깥 링.
