# 밤차 — INTERACTION.md

움직이는 장치는 없다. 작은 조작 셋만 있고, 모두 마우스·터치·키보드로 같은 일을 한다.

## 1. 시각표 날짜와 방향

- 날짜: 라디오 7개(오늘 밤부터 7일). 화살표 키로 옮기고, 고르면 표의 요금·남은 자리·캡션이 바뀐다.
  금·토 밤은 주말 요금. 표 캡션(화면 낭독기용)에 날짜와 "주말 요금"이 들어간다.
- 방향: 둘 다 / 남쪽으로(1호) / 북쪽으로(2호) 라디오. 표에서 해당 열차 묶음만 남긴다.
- 상태: 선택 = 밤 파랑 칸, hover = 테두리 진하게, focus = 3px 밤 파랑 실선.
- 매진 행: 요금에 취소선, "매진", 고르기 링크 없음.

## 2. 시각표 → 예약

- 각 행의 "고르기"는 `#book` 으로 가는 링크다. 누르면 예약 칸의 날짜·방향·객실을 그 행 값으로 맞춘 뒤 이동한다.
  링크 이름에 편과 객실이 들어간다("고르기: 1호 2인실").

## 3. 예약 칸 (데모)

- 방향(라디오 2), 출발하는 밤(select, 14일), 객실(라디오 3, 그날 요금 표시), 사람 수(− / + 버튼, `output` 은 `aria-live`).
- 사람 수 한도: 1인실 1명, 2인실 2명, 4인 침대칸은 남은 자리와 4 중 작은 값. 한도에서 버튼 비활성.
- 요약은 바뀔 때마다 즉시 다시 쓴다: 날짜, 출발·도착 시각, 객실·인원·도착일, 합계, 남은 자리(예시).
- 매진이거나 침대칸 남은 자리보다 많이 고르면 "예약 내용 확인" 비활성과 안내 문장.
- 제출: 아무 데도 보내지 않는다. `role=status` 문장으로 "데모라서 예약은 만들어지지 않았고 어디에도 보내지 않았다"를 알린다.

## 4. 머리글 메뉴 (1023px 이하)

- 메뉴 버튼(`aria-expanded`, `aria-controls="nav"`)이 메뉴 목록을 펼친다. 링크를 누르거나 Esc 를 누르면 닫히고,
  Esc 로 닫으면 초점이 메뉴 버튼으로 돌아온다.
