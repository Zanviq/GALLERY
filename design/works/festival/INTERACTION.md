# 너울 2027 — 인터랙션 명세

Saffer의 트리거 · 규칙 · 피드백 · 루프/모드로 정리. 구현은 `works/festival/js/`.

## 0. 전역 상태

```
state = {
  day: 'fri' | 'sat' | 'sun'      // 하나뿐. 히어로 탭, 시간표 탭이 같은 값을 바꾼다
  sound: 'off' | 'starting' | 'playing' | 'paused-hidden' | 'unavailable'
  picks: Set<actId>               // localStorage 'neoul27:picks'
  reserved: { tierId: {qty, code, day?} }   // localStorage 'neoul27:tickets'
  motion: 'full' | 'reduced'      // prefers-reduced-motion
}
```
- 마지막으로 본 날은 `localStorage 'neoul27:day'`에 둔다(다음 방문의 기본값). 저장소를 못 쓰면 메모리에서만 동작하고 아무 말도 하지 않는다.

## 1. 키네틱 라인업 (시그니처)

**구성.** 날마다 이름 10개를 3–6줄로 조판. 줄마다 `wdth`를 풀어 폭에 꼭 맞춘다(레이아웃 시, 리사이즈 시만). 글자마다 `<span>`. 시각용 포스터는 `aria-hidden`, 스크린리더용 평범한 목록(`<ol>`)은 따로 있다.

| 입력 | 규칙 | 피드백 |
|---|---|---|
| 커서/손가락 위치 | 글자 중심과 거리 d, 반경 R = clamp(150px, 26vw, 420px). `p = smoothstep(R, 0, d)` | 날마다 다르게: 금은 `wght` 700→150·`wdth` +52(검은 이름 속에 가늘고 넓은 렌즈), 토는 300→900, 일은 520→900. 줄 전체는 `scaleX`로 폭을 지켜서 먼 글자는 눌린다 = 물결이 "부푼다" |
| 스크롤 속도 v (px/ms, 지수 평활) | 줄마다 다른 강성의 스프링으로 v를 따라감(위 줄이 먼저, 아래 줄이 늦게) | `skewX(clamp(-v·7, ±12°))`, `scaleY(1 + min(|v|·0.14, 0.3))`. 멈추면 0.5초 안에 제자리 |
| 소리(재생 중) | 킥 → 엔벨로프 k(τ 170ms). 스펙트럼(로그 축 40Hz–9kHz)을 글자의 가로 위치에 대응. 줄 i는 i×5프레임 전 스펙트럼 = 위에서 아래로 흐르는 스펙트로그램 | 글자 `wght` += (900−기본)·(0.75·s + 0.25·k). 너울 워드마크도 킥에 맞춰 굵어짐 |

**루프.** rAF 한 개. 입력이 없고 모든 글자가 목표값 ±0.5 안이면 루프를 멈춘다(렌더 온디맨드). 히어로가 화면 밖이거나 탭이 숨으면 멈춘다. 쓰기(글자 축) → 읽기(줄 폭, 한 번) → 쓰기(transform) 순서로 프레임당 강제 레이아웃 1회.

**휴대폰.** 손가락을 대고 끄는 동안만 근접 효과(pointerType touch). 손을 떼면 0.6초에 걸쳐 가라앉는다. 스크롤 속도 효과는 그대로. 이름이 너무 작아지면(폭 50에서도 글자 크기 < 최소) 이름을 단어 단위로 줄바꿈.

**동작 줄이기.** 축은 기본값에서 고정, transform 없음, 루프 없음. 포스터는 정지된 생성 포스터.

## 2. 날 바꾸기 (다시 조판)

트리거: 히어로 탭 / 시간표 탭 (`role=tablist`, ←/→/Home/End, 자동 선택).

규칙 · 시퀀스 (전체 약 800ms, 끊을 수 있음):
1. 0ms — 탭 선택 표시, `--day*` 토큰 교체 예약, 라이브 영역에 "9월 4일 토요일 라인업 10팀" 알림.
2. 0–320ms — 나가는 줄: 위에서부터 40ms 간격, 글자 `wght` → 100, `wdth` → 50, 줄 `scaleX` → 0(왼쪽 기준). 동시에 새 요일 색 면이 왼쪽에서 오른쪽으로 닦아 들어옴(clip-path, 520ms).
3. 320ms — 이름 교체, 줄 다시 맞춤, 생성 도형 다시 그림.
4. 320–800ms — 들어오는 줄: 위에서부터 45ms 간격, `scaleX` 0 → 맞춤값, 글자 `wght` 100 → 기본값(활자가 차오름).
- 진행 중에 다른 날을 누르면 현재 값에서 바로 새 시퀀스를 시작(입력을 막지 않음).
- 소리가 나는 중이면 다음 마디 첫 박에서 패턴·템포가 바뀐다.
- 동작 줄이기: 즉시 교체, 닦기 없음.

## 3. 소리 도크

```
[off] --누름--> [starting] --컨텍스트 준비--> [playing]
[playing] --누름--> [off]               (0.25s 페이드아웃 후 suspend)
[playing] --탭 숨김--> [paused-hidden] --탭 보임--> [playing]
[*] --AudioContext 없음--> [unavailable]   버튼 비활성 + 이유 문장
```
- 절대 자동 재생하지 않는다. 첫 소리는 버튼을 누른 뒤에만.
- 버튼은 `aria-pressed`. 글자: "소리 켜기" / "소리 끄기". 옆에 BPM과 그날 이름.
- 16칸 스텝 표시가 박에 맞춰 이동(동작 줄이기: 표시하지 않고 "재생 중" 글자만).
- 마스터 볼륨 0.7에서 시작, 0.4s 페이드인.
- **패턴 고치기**(disclosure, `aria-expanded`): 4줄(북, 손뼉, 찰랑, 저음) × 16칸 토글. 격자는 roving tabindex — 화살표 이동, Space/Enter 토글. "원래 패턴" 버튼으로 그날 패턴 복원. 소리가 꺼져 있을 때 칸을 누르면 그 소리를 한 번 들려주지 않는다(재생 전엔 무음 원칙).
- 고친 패턴은 날마다 메모리에 유지(새로고침하면 원래대로).

## 4. 시간표

- 무대 필터: 라디오 그룹 "전체 / 물마루 / 소금창고 / 모래톱" — 빈 결과가 생기지 않게 단일 선택.
- "내 선택만" 토글(aria-pressed). 고른 게 없으면 빈 상태 문장 + 해제 버튼.
- 공연 칸 = 토글 버튼(`aria-pressed`, 이름 · 무대 · 시간을 읽음). 누르면 요일 색 면 + 체크. 같은 날 고른 공연끼리 시간이 겹치면 두 칸 모두 "시간 겹침" 표시(클래시 파인더).
- 720px 미만: 격자 대신 시간순 목록(무대 이름 붙음). 같은 토글.
- 담은 수 표시: "내 선택 3". 저장은 즉시, 피드백은 칸 자체의 변화로 충분(토스트 없음).

## 5. 티켓 예약 (가상)

```
[available] --수량 고르기(1–4, 범위 밖 버튼 비활성)--> [available]
[available] --예약하기--> [holding 450ms "자리 잡는 중"] --> [reserved]
[reserved] --예약 취소--> [available]
[soldout] (얼리 사흘권)  버튼 없음, "마감" 표시
```
- reserved 표 쪽: 예약 번호(NE27-XXXX), 권종, 수량, 날짜(하루권), 합계, "가상 예약입니다. 결제도 개인정보 입력도 없습니다."
- 하루권은 날 선택(라디오, 기본값 = 현재 보고 있는 날).
- 아무것도 전송하지 않는다. localStorage에만 남긴다.

## 6. 그 밖

- 메뉴(900px 미만): 버튼 `aria-expanded`, 전체 화면 패널, Esc로 닫기, 포커스 가둠, 닫으면 버튼으로 포커스 복귀.
- 지도: 셔틀 길 점선이 화면에 들어올 때 한 번 그려짐(1.2s). 동작 줄이기: 처음부터 다 그려진 상태.
- FAQ: `details/summary`, + → × 회전 160ms.
- 캔버스 실패: 생성 도형 없이 평평한 요일 색 포스터. JS 없음: 평범한 라인업 목록이 보인다.
