# 너울 2027 — DESIGN.md

가상의 서해안 음악 축제 **너울 NEOUL 2027** 홈페이지(`works/festival/`)의 디자인 결정.
토큰은 `works/festival/css/site.css` 맨 위 `:root`에 같은 이름으로 들어 있다. 페이지 코드는 이름만 쓴다.

> 참고: UXKIN이 연결돼 있지 않아 실제 사이트 비교 없이 브리프와 페스티벌 포스터 관행(라인업 블록, 요일별 색, 정렬된 이름 줄)에 기대어 정했다.

## 1. 한 줄 방향

**포스터가 그대로 움직이는 사이트.** 소금곶 옛 염전에서 열리는 사흘짜리 축제. 라인업 활자가 히어로이고, 활자는 스크롤 속도·커서 거리·사이트가 직접 만든 음악에 반응해 "부푼다"(너울 = 큰 물결). 나머지는 축제 안내서처럼 실용적으로: 시간·가격 같은 숫자는 크게, 장식은 없다. 괘선은 시간표·티켓처럼 정보를 나눌 때만 쓴다.

- 브랜드: 너울 음악 축제 2027 · NEOUL 2027 · 네 번째 너울
- 날짜: 2027년 9월 3일(금)–5일(일). 날마다 물때 이름: 들물(금) / 만조(토) / 썰물(일)
- 장소: 서해 소금곶 옛 염전 (가상). 무대 셋: 물마루(큰 무대) · 소금창고(목조 창고) · 모래톱(바닷가, DJ)

## 2. 색

포스터 인쇄처럼 **평평한 색 두세 개**만. 그라데이션, 글로우, 반투명 유리 없음.

| 토큰 | 값 | 역할 |
|---|---|---|
| `--salt` | `#EDEFEC` | 종이. 본문 섹션 배경. (크림이 아니라 소금빛 회백) |
| `--salt-2` | `#E1E4E0` | 표 머리, 눌린 칸, 지도 바다 |
| `--ink` | `#121413` | 글자, 괘선, 주 버튼. salt 위 16:1 |
| `--ink-2` | `#3D4340` | 보조 글자 (8.7:1) |
| `--ink-3` | `#5F6662` | 캡션·메타 (salt 위 5.1:1, salt-2 위 4.6:1) |
| `--rule-soft` | `rgb(18 20 19 / .16)` | 표 안쪽 가는 선 |

**요일 색 (전통 안료 이름).** 히어로 배경, 강조, 선택 상태가 모두 `--day*`를 따라 바뀐다.

| 날 | `--day` (바탕) | `--day-ink` (그 위 글자) | `--day-deep` (톤온톤 도형) | `--day-text` (salt 위 글자색) |
|---|---|---|---|---|
| 금 · 들물 · 주홍 | `#EE4A26` | `#121413` (4.97:1) | `#C9361A` | `#B3321A` (5.4:1) |
| 토 · 만조 · 군청 | `#2741D6` | `#EDEFEC` (6.45:1) | `#1C2FA8` | `#2741D6` (6.45:1) |
| 일 · 썰물 · 치자 | `#F4B71C` | `#121413` (10.3:1) | `#D99A00` | `#7A5600` (5.75:1) |

규칙: 노랑·주홍을 salt 위 글자색으로 쓰지 않는다(`--day-text`를 쓴다). 큰 라인업 활자는 3:1 이상, 나머지 글자는 4.5:1 이상.

## 3. 활자

| 역할 | 서체 | 축 / 굵기 | 이유 |
|---|---|---|---|
| 라인업·숫자 (라틴) | **Anybody** (OFL) | `wdth` 50–150, `wght` 100–900, italic | 폭 축 범위가 넓어 한 줄을 폭으로 맞출 수 있다. 키네틱 효과의 엔진 |
| 한글 디스플레이 | **Hahmlet 함렛** (OFL) | `wght` 200–900 | 굵은 현대 명조. 라틴 그로테스크와 대비, 가변이라 한글 이름도 부푼다 |
| 본문·UI | **IBM Plex Sans KR** (OFL) | 400 / 500 / 600 | 시간표·표에 맞는 단단한 고딕, `tnum` 숫자 |

타입 스케일 (root 16px):

| 토큰 | 크기 / 행간 | 쓰임 |
|---|---|---|
| `--t-xs` | 13px / 1.45 | 캡션, 지도 라벨 |
| `--t-sm` | 15px / 1.55 | 메타, 표 안 글자 |
| `--t-base` | 17px / 1.7 | 본문 (한 줄 34–40자, `max-width: 38em`) |
| `--t-lg` | 20px / 1.5 | 리드 문장 |
| `--t-xl` | clamp(24px, 2.4vw, 32px) / 1.25 | 소제목 (Hahmlet 700) |
| `--t-2xl` | clamp(40px, 6vw, 88px) / 1.0 | 섹션 제목 (Hahmlet 800) |
| `--t-3xl` | clamp(72px, 16vw, 240px) / .9 | 너울 워드마크 |
| 라인업 | 줄마다 폭에 맞춰 계산 | 헤드라이너 줄 > 중간 줄 > 작은 줄 |

- 라인업 줄은 글자 크기가 아니라 **폭 축(wdth)으로 화면 폭에 맞춘다**. 남는 차이만 `scaleX`(한글의 장평)로 메운다.
- 대문자 자간 벌린 머리표(eyebrow)는 쓰지 않는다. 섹션 번호도 달지 않는다(순서가 있는 내용이 아니므로). 번호는 오시는 길 단계처럼 실제 순서에만.
- 메타 정보를 가운뎃점(·)으로 잇지 않는다. 날짜·장소는 줄을 나눠 쌓는다. 버튼 글자 뒤에 화살표 문자를 붙이지 않는다.
- 영문 대문자는 라인업 이름에만.

## 4. 간격과 격자

- 4px 기반: `--s-1` 4 · `--s-2` 8 · `--s-3` 12 · `--s-4` 16 · `--s-5` 24 · `--s-6` 32 · `--s-7` 48 · `--s-8` 64 · `--s-9` 96 · `--s-10` 128
- 바깥 여백 `--gutter`: clamp(16px, 3vw, 40px). 섹션 위아래 `--section`: clamp(72px, 10vw, 152px)
- 최대 폭 1680px. 12칸 격자, 칸 사이 `--gutter`. 섹션 제목은 왼쪽 1–4칸, 내용은 5–12칸으로 비대칭. 모두 왼쪽 정렬(라인업 줄만 양끝 맞춤).
- 섹션은 면 색으로 나눈다: 히어로(요일 색) → 시간표(salt) → 티켓(ink) → 오시는 길(salt-2 지도 + salt) → FAQ(salt) → 푸터(요일 색). 신문식 촘촘한 단·가는 괘선 반복은 피한다.

## 5. 모양과 깊이

- 모서리 `--r: 0`. 예외: 재생 버튼과 무대 점은 원.
- 그림자 없음. 깊이는 괘선(2px ink / 1px rule-soft)과 면 색 바꿈으로만.
- 표 칸 선택은 면을 `--day`로 채운다.

## 6. 컴포넌트

- **버튼** — 주: ink 면 + salt 글자, hover 시 `--day` 면 + `--day-ink` 글자. 보조: 2px ink 테두리. 조용한: 밑줄 링크. focus: 3px 실선 outline, offset 3px (`--focus`: 밝은 바탕에선 ink, 어두운 바탕에선 salt). disabled: 40% 투명 + 사선 무늬 없이 `cursor: not-allowed`.
- **날 선택(탭)** — 세 칸 segmented. `9.3 금 들물`처럼 날짜 숫자가 크게. 선택 칸은 ink 면.
- **소리 도크** — 화면 오른쪽 아래 고정. 재생/정지 버튼(원), 16칸 스텝 표시, BPM. 펼치면 4트랙×16칸 시퀀서. 소리는 누르기 전엔 절대 나지 않는다.
- **시간표** — 무대 × 시간 격자(15분 단위). 공연 칸은 salt-2 면 + ink 글자, 고른 공연은 `--day` 면 + 체크. 무대 필터는 토글 버튼(aria-pressed). "내 선택"은 localStorage에 저장.
- **티켓** — 카드 3개 대신 **표 쪽(stub) 목록**: 한 줄에 권종 · 포함 내용 · 가격 · 수량 · 버튼, 오른쪽은 점선 절취선. 예약하면 같은 자리에서 "예약됨" 표 쪽으로 바뀐다(가상, 아무것도 전송하지 않음).
- **FAQ** — `details/summary`, 오른쪽 + 기호가 ×로 45° 회전.
- **지도** — 손으로 그린 듯한 SVG: 해안선, 염전 칸, 역, 셔틀 길(점선), 무대 셋, 캠핑장, 주차장.
- **푸터** — `--day` 띠, 큰 너울 워드마크, 한 줄 고지.

## 7. 이미지와 아이콘

- 사진 없음. 모든 시각 요소는 활자, 생성 도형(물결선·해/달 원·염전 격자), SVG 지도.
- 아이콘: 직접 그린 인라인 SVG, 24px 격자, 1.75px 선, 각진 끝. 이모지 금지.
- 요일별 생성 포스터: 씨앗(seed) = 날짜. 같은 날은 항상 같은 포스터. 도형은 `--day-deep` 톤온톤.

## 8. 움직임

- 움직이는 건 **라인업 하나**. 다른 섹션은 나타나기 효과 없음.
- UI 전환 150–220ms, `cubic-bezier(.2,.7,.2,1)`.
- 날 바꾸기: 옛 이름은 폭 50·굵기 100으로 접히고, 새 이름이 줄마다 엇갈려 펼쳐진다(약 700ms).
- `prefers-reduced-motion: reduce` (2026-11-10 수정, BRIEF §000 "멈춤이 아니라 차분하게"): 주인 PC가 애니메이션 효과를 꺼 둬서 예전의 정지 포스터가 "생동감이 사라진" 페이지로 보였다. 이제 동작 줄이기에서도 커서·손가락에 부푸는 활자, 소리에 맞춘 활자·물결·스텝 불빛, 날 바꾸기 색 닦기, 지도 길 그리기(0.9s)가 그대로 움직인다. 빼는 것은 세 가지뿐: 부드러운 스크롤, 스크롤 속도에 따른 기울기·늘림, 날 바꿀 때 줄이 0까지 접혔다 펼쳐지는 큰 축소(대신 줄이 흐려졌다 나타남). 평범한 목록은 동작과 상관없이 스크린리더용으로만 둔다.
- 캔버스를 못 쓰면 CSS 면색 포스터로 대신한다.

원칙
1. 움직이는 건 활자뿐. 방문자의 손(커서·스크롤·재생 버튼)이 활자를 움직인다.
2. 하루 = 포스터 한 장. 색, 축 값, 도형이 모두 그날의 씨앗에서 나온다. 날을 바꾸면 포스터를 다시 짠다.
3. 정보는 안내서처럼. 시간·가격·거리는 크게, 설명은 짧게.
4. 평평한 잉크와 평평한 면. 그라데이션·글로우·그림자·블러 없음.

검토에서 바꾼 것
- 처음 안: 종이 섹션 전체를 신문처럼 2px 괘선과 번호(01/02…)로 나눔 → 생성형 사이트의 "브로드시트" 기본값과 같아서 버림. 섹션은 면 색으로 나누고 번호는 실제 순서(오시는 길 단계)에만.
- 처음 안: 날짜 메타를 `9.3 · 금 · 들물`처럼 가운뎃점으로 이음 → 쌓아 올린 날짜 블록으로 바꿈.
- 처음 안: 티켓을 어두운 면 + 형광 강조 하나 → 어두운 면은 쓰되 강조색이 요일마다 바뀌어 "검정 + 한 가지 형광" 공식이 되지 않게.

## 10. 구현 메모 (빌드 후)

- 날마다 활자의 대답이 다르다: 금(들물)은 굵고 좁은 이름이 커서 근처에서 가늘고 넓게 열린다(물의 렌즈), 토(만조)는 가는 이름이 검게 부푼다, 일(썰물)은 이탤릭이 굵어진다. 소리를 켜면 같은 방향으로 스펙트럼이 글자를 민다(왼쪽 = 저음, 줄마다 5프레임씩 늦게 = 위에서 아래로 흐르는 스펙트로그램).
- 성능: 새 (크기, 굵기, 폭) 조합마다 브라우저가 폰트 인스턴스를 만들어서 비싸다. 굵기는 20, 폭은 4% 단위로 끊고, 한 프레임에 바꾸는 글자는 24개(터치 기기 12개)까지, 많이 움직인 글자부터. 글자를 바꾼 프레임에만 줄 폭을 한 번 읽는다.
- 한글만 있는 줄은 폭 축이 없으니 글자를 늘리지 않고 크기를 키운 뒤 자간으로 맞춘다. 줄을 나눌 때 한글 이름이 혼자 남지 않게 한다.
- 헤더는 히어로 색 면 위에 얹혀 있어 날 바꾸기 닦기(wipe)가 헤더까지 덮는다. 색 전환 transition은 쓰지 않는다(빨강과 파랑 사이의 보라가 보이므로).
- `data-day`는 `<html>`에 있고 첫 페인트 전에 인라인 스크립트가 정한다(마지막으로 본 날, `?day=`).
- 캡처: `?capture`(썸네일, 첫 줄에 손을 얹은 순간), `?capture=og`(헤더·탭 숨김, 세 줄까지). `scratch/export_images.py`가 webp/png로 바꾼다.
- 폰트: `scratch/subset_fonts.py`가 쓰인 글자만 woff2로 자른다. 문구를 바꾸면 다시 돌린다.
