# 깊은쪽 《물 빼는 날》 — DESIGN.md

가상의 4인조 밴드 **깊은쪽**의 첫 정규 LP **《물 빼는 날》** 발매 홍보 페이지(`works/record/`).
토큰은 `works/record/css/site.css` 맨 위 `:root`에 같은 이름으로 있다.

> 참고: UXKIN 이 연결돼 있지 않아 실제 사이트 비교 없이, 01 가락 65 · 02 너울 2027 · 03 담금을 직접 열어 보고
> 레코드 발매 포스터의 관행(앞면 재킷, 면별 수록곡, 발매일·가격·청음회를 크게)에 기대어 정했다.

## 1. 한 줄 방향

**판 한 장을 알리는 포스터, 그리고 그 판을 걸어 볼 수 있는 턴테이블 한 대.**
첫 화면은 인쇄된 발매 포스터처럼: 청록 면, 화면만 한 제목, 재킷에서 반쯤 나온 청록 판, 발매일·가격·예약.
그 아래 검은 칸 하나에서 판이 33⅓회전으로 돌고, 바늘을 내리면 그 자리의 곡이 (브라우저가 만든 소리로) 흐르고
옆 수록곡 줄이 켜진다. 나머지는 음반 안내서처럼 사실을 크게, 설명은 짧게.

## 2. 이야기 (모두 가상)

- 밴드: 깊은쪽 (반서하 노래·기타, 모해솔 베이스, 길도연 드럼, 표은재 건반). 밴드 사진은 쓰지 않는다. 밴드는 물건으로 보인다:
  물 뺀 수영장 바닥에 쉬고 있는 악기, 재킷, 판, 테스트 프레싱, 가사지(활자로 조판).
- 음반: 첫 정규 《물 빼는 날》, 소리골 레코드 SRG-001, 2027년 3월 12일 발매. A면 5곡 19:21, B면 5곡 22:32.
- 녹음: 문을 닫고 물을 뺀 옛 잔물시립 실내수영장에서 2026년 8월 12일 동안. 타일 벽의 잔향 2.4초가 이 음반의 소리다.
- 판: 12인치, 33⅓회전, 180g 청록반 500장(번호), 4월에 검정 일반반.
- 예약 39,000원, 2월 28일까지. 예약처 = 소리골 레코드 상점 + 판가게 세 곳(같은 가게에서 청음회).
- 발매 공연: 3월 20일(토) 옛 잔물시립 실내수영장, 물 뺀 수영장 바닥 스탠딩 300명, 33,000원.
- 지명은 모두 지어냈다(잔물시, 잔물역, 물받이로, 회전구 바늘길, 줄눈구 타일길). 주소마다 "가상 서비스입니다. 실제 주소가 아닙니다."

## 3. 색

판 한 장에서 온 세 가지. 그라데이션, 글로우, 반투명 유리 없음.

| 토큰 | 값 | 역할과 이유 |
|---|---|---|
| `--vinyl` | `#00A3A1` | 청록반의 색. 첫 화면·예약·바닥글 면, 켜진 수록곡 줄, 선택 상태. 녹음한 수영장 타일의 색이기도 하다(재킷 사진) |
| `--ink` | `#000000` | 턴테이블 칸(판을 얹는 검은 상판), 모든 글자와 괘선, 주 버튼 |
| `--paper` | `#FFFFFF` | 이야기·판·만든 사람 칸의 바탕, 판 가운데 라벨, 가사지 |
| `--ink-2` | `#3E4545` | 흰 바탕 보조 글자 (9.9:1) |
| `--mute` | `#A3ADAD` | 검은 바탕 보조 글자 (8.9:1) |

대비: ink/vinyl 6.75, vinyl/ink 6.75 (검은 칸의 청록 글자), ink/paper 21, ink-2/paper 9.9, mute/ink 8.9.
paper/vinyl 3.1 은 큰 글자(24px 이상 굵게)에만. 청록 글자를 흰 바탕에 작게 쓰지 않는다.
금지 팔레트와의 거리: 청록 + 코랄 아님(강조색은 없다), 검정 위 네온 글로우 아님(평평한 면만), 크림 아님(종이는 순백).

## 4. 활자

| 역할 | 글꼴 | 쓰임 |
|---|---|---|
| 디스플레이 | **Moirai One** (OFL, RFN 없음) | 제목 《물 빼는 날》, 큰 날짜·가격, 섹션 제목, 바닥 워드마크. 획이 속이 빈 한 줄 윤곽이라, 판의 소리골처럼 한 줄로 이어진 선으로 읽힌다. `-webkit-text-stroke` 로 윤곽을 크기에 맞게 굵게(0.012em) |
| 본문·UI | **Gipeun Sans** = 나눔바른고딕 400/700 부분집합, 이름 바꿈 (NAVER 가 NanumBarunGothic 을 Reserved Font Name 으로 둠) | 본문, 수록곡, 표, 버튼. 숫자가 고정폭(583)이라 흐른 시간이 흔들리지 않는다 |
| 라틴 | 없음 | Darker Grotesque 를 예약해 두었으나 쓰지 않았다. 바른고딕의 라틴과 숫자로 충분 |

크기 (root 16px):
- 히어로 제목: clamp(88px, 15vw, 260px) / 0.92, 휴대폰은 한 줄에 두 글자씩 세 줄.
- 섹션 제목: clamp(56px, 8vw, 132px) / 1 (Moirai One).
- 큰 사실(날짜·가격): clamp(64px, 9vw, 150px).
- 리드: clamp(20px, 1.9vw, 26px) / 1.55, 본문 17px / 1.75 (max 36em), 메타 14px.
- 대문자 머리표·섹션 번호 없음. 수록곡 번호(A1…B5)는 실제 순서라 예외. `word-break: keep-all`.

## 5. 격자와 간격

- 12칸, 바깥 여백 `--gutter` clamp(16px, 3.2vw, 48px), 칸 사이 `--gap` clamp(12px, 1.6vw, 24px), 최대 폭 1600px.
- 섹션 위아래 `--section` clamp(96px, 12vw, 184px).
- 섹션 머리는 왼쪽 제목(1–6칸) + 오른쪽 리드(8–12칸), 둘 다 위에 3px 괘선. 표 안쪽만 1px.
- 섹션은 면 색으로 나눈다: 첫 화면(vinyl) → 턴테이블(ink) → 이야기(paper) → 판(paper, 가사지 면은 vinyl) →
  예약(vinyl) → 발매 공연(ink) → 만든 사람(paper) → 바닥(vinyl).
- 모서리 0. 그림자는 판과 톤암의 바닥 그림자(사진 물건이 면 위에 놓였다는 표시)에만.

## 6. 사진

생성 사진(IMAGES.md). 사람·손·얼굴 없음. 맑은 낮빛의 디지털 사진(필름 입자 없음): 수영장 천창 빛.
- 판(위에서): 원을 맞춰 알파로 잘라 냄(`scripts/cut_vinyl.py`). 라벨은 비워 두고 HTML 활자로 라벨을 얹어 함께 돈다.
  판에 박힌 반사광은 회전 대칭으로 눌러 지우고, 고정된 빛띠(나비 모양)는 따로 얹어 돌지 않게 한다.
- 톤암(위에서): 크로마 초록 바탕에서 알파로 잘라 냄. 회전축과 바늘 끝 좌표를 재서 CSS 회전 중심으로 쓴다.
- 재킷 앞면: 물 뺀 수영장 깊은 쪽 벽 사진 + 활자. 재킷은 그래픽 사각형이고, 판만 사진 물건이다.
- 물 뺀 수영장 바닥에 쉬고 있는 악기, 스핀들에 쌓인 청록반, 하얀 라벨 테스트 프레싱.
- 보정: 청록은 `--vinyl` 쪽으로, 흰 줄눈은 순백 쪽으로, 그림자는 차가운 검정으로.

## 7. 컴포넌트

- 주 버튼: ink 면 + paper 글자, 높이 52px, hover 시 paper 면 + ink 글자 + 2px ink 테두리. 검은 칸에서는 vinyl 면 + ink 글자.
- 보조 버튼: 2px 테두리. 토글(소리, 바늘, 면)은 `aria-pressed`, 켜진 것은 면을 채운다.
- 포커스: 3px 실선 outline, offset 3px. 밝은 면에서는 ink, 검은 칸에서는 vinyl.
- 수록곡 줄: 번호 · 제목 · 길이. 켜지면 vinyl 면 + ink 글자, 길이 자리에 흐른 시간 "1:12 / 3:48".
- 표(사양, 예약처): 3px 위 괘선, 1px 줄 괘선, 숫자는 오른쪽 정렬.

## 8. 움직임

- 움직이는 것은 턴테이블 칸 하나: 판(33⅓회전 = 1.8초에 한 바퀴), 톤암, 켜진 줄의 시간. 다른 섹션은 나타나기 효과 없음.
  첫 화면은 정지한 포스터이고, 재킷에 포인터를 올리면 판이 6% 더 나오며 24° 돈다(0.7초) — 그것 하나만.
- 재킷 디자인: 흰 종이 사각형, 위 23%는 활자 띠(왼쪽 Moirai 제목, 오른쪽 밴드 이름과 SRG-001), 아래 77%는 깊은 쪽 벽 사진.
- UI 전환 160–220ms, `cubic-bezier(.2,.7,.2,1)`. 톤암 이동 거리 비례 300–700ms, 바늘 내림 280ms.
- `prefers-reduced-motion: reduce`(넷째 검토: 차분하게, 멈춤이 아니라): 판은 그대로 돌고, 바늘·소리·줄 켜짐도 그대로.
  빼는 것: 부드러운 스크롤, 판 뒤집기의 가로 접힘(대신 흐려졌다 나타남). 회전 속도는 실제 속도 그대로(판의 요점).
- 칸이 화면 밖이거나 탭이 숨으면 회전·소리를 멈추고, 돌아오면 그 자리에서 잇는다.
