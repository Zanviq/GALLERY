홈 대시보드 시안

4안. 각 시안은 단독 페이지로 열리고, 같은 더미 작품 12점을 씁니다.

A

살롱 월

작품을 긴 벽 하나에 크기를 섞어 걸었습니다. zanviq.dev의 종이 질감과 라벤더 톤, 라벨 스티커를 그대로 가져왔습니다.

탐색
가로로 긴 벽을 휠, 드래그, 하단 축소 지도로 이동
인터랙션
빠르게 밀면 액자가 못에 걸린 채 흔들림. 태그를 고르면 다른 작품은 벽에서 내려가고 자국만 남음
시안 A 열기
B

복도

CSS 3D로 만든 전시 복도를 스크롤로 걸어 들어갑니다. 짙은 녹색 벽과 조명의 미술관 톤입니다.

탐색
스크롤하면 앞으로 걸음. 왼쪽 아래 평면도를 눌러 원하는 위치로 이동. 목록 보기로 전환 가능
인터랙션
다가가면 조명이 켜지고 액자가 나를 향해 돌아섬. 외부 사이트는 문으로 걸려 있다가 가까이 가면 열림
시안 B 열기
C

오락실

오락기 한 대 안의 작품 선택 화면입니다. zanviq.dev 톤에서 일부러 벗어난 실험안입니다.

탐색
방향키나 조이스틱으로 칸 이동, Q E 또는 B 버튼으로 분류 전환
인터랙션
CRT 켜짐, 모자이크가 풀리는 미리보기, 선택 시 깜빡임, 동전을 넣으면 문의 화면. 가만히 두면 데모 모드
시안 C 열기
D

출발 안내판

작품 목록을 공항 플랩 안내판으로 보여 줍니다. 한 줄에 연도, 작품, 행선지(주소), 분류, 상태가 다 보이는 인덱스형입니다.

탐색
줄을 훑고 누르면 이동. 연도, 작품 이름으로 정렬
인터랙션
필터나 정렬을 바꾸면 글자판이 한 칸씩 넘어가며 새 목록으로 바뀜. 줄에 올리면 오른쪽 모니터에 썸네일
시안 D 열기

작품 링크는 시안 단계라 실제로 이동하지 않고 어디로 갈지 안내만 띄웁니다. 카카오톡 오픈채팅 주소는 자리만 잡아 두었습니다.
